# WEDE5020-PART3
PART3 SUBMISSION 
Jabu’s T&H Beauty Salon Website

1. Project Description

Jabu’s T&H is a beauty salon website developed to promote the business and its beauty services. The website aims to improve the salon’s online presence, attract new customers and provide information about available services and salon locations.

The business offers makeup services, hair installations, hairstyling and nail services.

2. Website Objectives

* Promote Jabu’s T&H beauty salon online.
* Display the services offered by the business.
* Share information about the salon and its history.
* Showcase beauty work through a photo gallery.
* Provide customers with contact and enquiry information.

3. Website Pages

The website consists of five main pages:

* Home: Introduces the business and highlights its services.
* About Us: Provides information about the business, its background, mission and vision.
* Services: Displays the beauty services offered.
* Gallery: Showcases examples of beauty work.
* Contact Us: Provides branch information and an enquiry form.

4. Technologies Used

* HTML5 – Website structure.
* CSS3 – Website styling and layout.
* JavaScript – Website interactivity and form validation.
* Bootstrap – Responsive design framework (if used).

5. Website Design

The website uses a black, gold, white, nude beige and soft pink colour scheme to create an elegant and professional beauty salon appearance.

6. Target Audience

The website targets women and individuals interested in beauty, makeup, hairstyling, hair installations and nail services.

7. Branch Locations

* Khayelitsha, Cape Town.
* Delft, Cape Town.

The website can be accessed through the published GitHub Pages link once deployment is complete.
